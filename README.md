# جاردينيا - حساب الطاولات

تطبيق ويب بسيط (HTML + CSS + JavaScript عادي، من غير مكتبات) لحساب طلبات الطاولات في الكافيه. البيانات بتتحفظ في `localStorage` على نفس الجهاز.

## المميزات
- طاولات متعددة + إضافة/حذف طاولة
- **اسم للطاولة واسم للعميل** (زي: طاولة 1 - ابراهيم) من زر ✎ تعديل
- منيو كامل بالبحث والأقسام + **إضافة صنف مخصص** مش في المنيو
- **تعديل سعر أي صنف** داخل الطلب (للطلب ده بس)
- **تعديل الإجمالي** يدويا، مع زر الرجوع للحساب التلقائي
- خصم، ملاحظات على الطلب، نسخ الفاتورة
- قفل الفاتورة + تقرير اليوم
- **بلايستيشن:** 4 أجهزة، لكل جهاز سعر ساعة خاص، ومؤقت (ابدأ/إيقاف) أو كتابة الساعات بإيدك (1.5 أو 1:30)، ويقبل مشروبات من المنيو
- **سجل بالتاريخ واليوم:** كل فاتورة بتتحفظ بتاريخها ووقتها، وتتصفح الأيام السابقة أو تختار تاريخ (اليوم بيبدأ 5 الفجر)
- نسخة احتياطية (تصدير/استيراد JSON) من ⚙

## هيكل الملفات
```
index.html
css/style.css     التصميم
js/menu.js        المنيو والأسعار (عدّل الأسعار هنا)
js/state.js       الحالة والحفظ والحسابات
js/ui.js          نافذة التعديل وأدوات مساعدة
js/app.js         الشاشات والتفاعل
```

## تعديل أسعار المنيو للأبد
افتح `js/menu.js` وغيّر الرقم بعد `=`. للأصناف ذات الحجمين: `سعر1/سعر2`.
